CONTOUR.
VISUAL TRACKER.

Contour is a music tracker I'm developing for Anbernic H700 handhelds and Windows. It combines pattern sequencing, sampling, a collection of small synths and generative visuals. I'm also working towards a way for devices to exchange music directly.

The starting points were LSDj and ProTracker, along with ideas from M8, Polyend, Korg Gadget, the Game Boy Camera and 3DS.

01 / TRACKER

Learning to use a tracker

If you're used to a DAW, a tracker can look like a spreadsheet full of numbers. I want Contour to make that transition easier without losing the things that make trackers useful: precise timing, reusable patterns and fast editing.

See what the commands actually do

Song, Chain, Roll and Phrase show the music at different levels. You can build a short idea, reuse it and see how it fits into an arrangement.

The tracker still uses notes, effect commands and hexadecimal values. The aim is to show what those values are changing, so you can learn as you go rather than memorise a command list before you start.

02 / INSTRUMENTS

Instruments are where the sound starts.

In Contour, the tracker tells an instrument what note to play and what to do with it. The instrument determines the sound. That might be a single sample, a sliced break, a drum kit or one of the synthesizer engines.

SAMPLE INSTRUMENTS

Single, slice and kit

Map a recording across notes, divide a break into slices or build a kit from separate hits. Other instrument layouts are being developed for round-robin and multisample work.

EDIT THE SOURCE

Work on the sample

Set start, end and loop points; crop, reverse, fade and normalise. Slice and processing tools are being developed so you can prepare material without leaving the tracker.

ONE WORKFLOW

Play them from the tracker

Pick an instrument in a phrase, enter notes and use tracker commands to change how it plays. Instruments can also use effects sends and modulation where supported.

Instrument types and editing tools will be listed in the release notes as they become available.

03 / SOUND DESIGN

A collection of smaller synths

I like the approach Korg Gadget takes: several instruments that are easy to recognise and quick to edit. Contour uses a similar idea, with separate synth engines rather than trying to put every synthesis method into one interface.

SYNTH / 01

Different sound engines

The planned range includes analogue-style synthesis, FM, phase distortion, wavetable methods and experimental engines. Each has a different set of strengths.

SYNTH / 02

Keep the controls manageable

Each engine has a smaller set of useful parameters, with a consistent way to edit them from the tracker.

SYNTH / 03

More control when needed

Macros, envelopes, modulation and effects let you go further without making the basic instrument difficult to operate.

The synth engines are still being developed. I'll list what's working in each release.

04 / VISUAL SYNTHESIS

A visual synth alongside the audio synths.

The visual system uses the same idea as the audio instruments: choose a generator, set a few parameters and control it from the music. I want visual effects to be something you can sequence, not just an animation running behind the tracker.

Use tracker events to change the picture

A note, step or pattern can be used as a point in time to trigger or change a visual. Parameters such as movement, position, colour and intensity can be mapped to tracker commands, macros or musical activity as the visual workflow develops.

For example, a phrase could drive a tunnel, change the speed of a plasma effect or switch to a terrain scene at a particular point in the song. Multiple generators can be combined through the compositor, much like layers in the arrangement.

05 / PERFORMANCE + VJ

Live music and visuals on a handheld

I want Contour to be useful for playing live, not only writing tracks. The idea is to control an arrangement, change sounds and effects, and run visuals from the same device. Something you could take to a small rave or demoparty.

Change the arrangement live

Move through song sections and vary patterns while the music is playing.

Control instruments while playing

Use macros and effects to change sounds without leaving the performance.

Control the visuals too

Switch between procedural scenes such as tunnels, terrain, plasma and glyph graphics, with layers for combining them.

External display support

I'd like to support showing the visuals on another screen where the hardware and firmware allow it.

06 / CREATIVE EXPERIMENTS

Generators and editing tools

There are times when I want to write every note, and times when I want a useful starting point. Contour includes tools I'm developing for chords, scales, grooves, pattern variations, samples and procedural artwork.

MUSIC

Chord Gun

Generate chord progressions, then adjust their complexity, spacing and voice leading.

RHYTHM

Grooves and pattern changes

Change a rhythm or pattern, listen to the result and keep the parts that work.

ART

Glyphs and greeblies

Generate tile-based artwork and graphic details for the visual scenes.

07 / CONNECTED MUSIC

Sharing music between devices

One of the longer-term ideas is StreetPass-style sharing. Two Contour devices could discover each other and exchange projects, instruments, presets or artwork, without requiring a central server for every transfer.

I'd also like files to keep creator details and remix history, so people can see where an idea came from. This part of Contour is still experimental.

11 / WHY CONTOUR EXISTS

Why I'm making Contour

I got into making electronic music with LSDj on a Game Boy. It was a small bit of hardware, but it gave me a way to write music and figure out how synthesis and sequencing worked.

Contour comes from that experience. I want people to have a way into trackers without having to work out everything alone. The visuals, instruments and learning tools are part of making the process easier to follow.

I don't see this as a project I'll finish at version 1.0 and leave behind. I want to keep developing it, documenting what I learn and making it useful to the community.

— Aisjam

12 / DEVELOPMENT NOTES

Development, originality and influences

Some background on how I'm building Contour and the projects that helped shape it.

ORIGINAL DEVELOPMENT

Built from the ground up

Contour is my own implementation of a music tracker and visual instrument. I have not decompiled firmware packages to develop it, and I have not built it from extracted Anbernic firmware or code taken from the trackers listed here. Licensed third-party libraries and dependencies are handled separately.

DEVELOPMENT PROCESS

AI-assisted programming

I use AI-assisted programming tools to help implement, review, debug and optimise parts of Contour. I direct the design, architecture and feature decisions, and I remain responsible for testing and evaluating the result. This is an independent project, not an AI-generated music service.

INFLUENCES

Where the ideas came from

LSDj, ProTracker, M8 and Polyend Tracker have influenced the music workflow. Korg Gadget has influenced the approach to smaller, focused synthesizers. The Game Boy, Game Boy Camera and Nintendo 3DS have influenced the handheld and visual aspects. These are creative references, not claims of affiliation or code reuse.
