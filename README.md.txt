# Contour – Visual Tracker

Contour is a portable music tracker for the Anbernic RG35XX Pro, Windows, and other H700-based handhelds. Inspired by LSDj, ProTracker, Polyend, M8, Korg Gadget, Game Boy Camera, and 3DS, it combines sequencing, synthesis, sampling, and generative visuals with a decentralised, StreetPass-style music-sharing ecosystem.

**Website:** https://aisjam.github.io/Contour-Visual-Tracker/ (once GitHub Pages is enabled)

**Downloads:** https://github.com/Aisjam/Contour-Visual-Tracker/releases

**Version history:** [CHANGELOG.md](CHANGELOG.md)

**Issues and feedback:** https://github.com/Aisjam/Contour-Visual-Tracker/issues

## Status

In development. No release is implied by this website starter.

## Publishing the website

1. Create a public GitHub repository named `Contour-Visual-Tracker` under `Aisjam`.
2. Upload the files in this folder to the repository root. Keep `index.html` at the top level.
3. In repository **Settings → Pages**, choose **Deploy from a branch**, **main**, **/(root)** and save.
4. Open https://aisjam.github.io/Contour-Visual-Tracker/ after deployment.
5. Update screenshots, copy, links, `versions.json` and `CHANGELOG.md` for each real release.

## Release process

1. Build and test a downloadable archive for supported hardware.
2. Record changes in `CHANGELOG.md` and `versions.json` (newest first).
3. Tag the software version (for example `v0.1.0`) and publish a matching GitHub Release with attached files and install instructions.
4. Push the website files to update the public version history.
